File-level


Comments mid-line (hub: z 0 0 # comment) → stripped correctly
Blank lines anywhere in the file → skipped
Zone / hub lines
Unknown keyword (not start_hub:, end_hub:, hub:, connection:) → fail
Missing name, x, or y (too few fields) → fail
Extra tokens between fixed fields and [ → fail
Extra tokens after ] → fail
Zone name contains - → fail
Zone name contains a space → fail
Duplicate zone name → fail
Coordinates are not valid integers → fail
More than one start_hub: → fail
More than one end_hub: → fail
No start_hub: at all → fail
No end_hub: at all → fail
start_hub: or end_hub: has zone=blocked → fail
max_drones on start_hub:/end_hub: → silently ignored per v1.5 spec, zone treated as unlimited capacity
Metadata block [...]
Unclosed [ with no matching ] → fail
Text before [ that isn't a fixed field → fail
Text after ] (trailing garbage) → fail
Token inside [...] with no = → fail
Token with empty key (=value) → fail
Token with empty value (key=) → fail
Token with empty value due to spaces (key=  ) → fail (spaces collapse on split, value becomes "")
Unknown key for a hub ([s=blue d=2]) → fail with list of allowed keys
Unknown key for a connection ([zone=normal]) → fail with list of allowed keys
Duplicate key in same block ([color=red color=blue]) → fail
Comma-separated style ([color=blue, max_drones=2]) → accepted, commas stripped
Tags in any order inside [...] → accepted
Missing metadata block entirely → accepted, defaults applied
Zone type and color
zone= value not in (normal, blocked, restricted, priority) → fail
Invalid color name → warning, defaults to white, continues
color= absent → defaults to white
zone= absent → defaults to normal
Capacity values
max_drones not a valid integer → fail
max_drones is zero or negative → fail
max_link_capacity not a valid integer → fail
max_link_capacity is zero or negative → fail
Connections
Connection references a zone not yet defined → fail
Connection references an unknown zone name → fail
Duplicate connection (a-b and b-a both defined) → fail
Self-connection (a-a) → fail
Connection pair has empty zone name (-b or a-) → fail
Connection pair has more or fewer than two names (no -, or a-b-c) → fail
max_link_capacity absent → defaults to 1
Post-parse cross-checks
No connections at all to a zone → warning, continues
Two zones share the same coordinates → warning, continues (affects heuristic efficiency)
Goal is structurally unreachable from start (BFS check) → fail before algorithm runs
Start or end zone is blocked → fail at parse time with specific message
